# 🏥 Healthcare Data Warehouse & ETL Pipeline

A complete end-to-end healthcare data integration project built using **SQL Server Integration Services (SSIS)**, **SQL Server 2025**, and **Power BI**.

---

## 📋 Project Overview

This project implements a full ETL pipeline that extracts synthetic healthcare data generated by **Synthea**, transforms it through a staging layer, and loads it into a dimensional data warehouse following a **Star Schema** model. The warehouse powers interactive Power BI dashboards for clinical, operational, and financial reporting.

---

## 🏗️ Architecture

```
SOURCE LAYER          STAGING LAYER         DATA WAREHOUSE        REPORTING
─────────────         ─────────────         ──────────────        ─────────
Synthea CSVs    →→→   8 Staging Tables →→→  6 Dimensions    →→→   Power BI
(8 CSV files)         (1.6M records)        7 Fact Tables         Dashboards
                                            (1.6M records)
```

## 🚀 How To Run This Project

### Prerequisites
- SQL Server 2019 or higher
- SQL Server Integration Services (SSIS)
- Visual Studio 2022 with SSDT extension
- Power BI Desktop

### Setup Steps

**Step 1 — Create Databases:**
```sql
-- Run SQL/01_Create_Databases.sql in SSMS
```

**Step 2 — Create Staging Tables:**
```sql
-- Run SQL/02_Staging_DDL.sql in SSMS
```

**Step 3 — Create DW Tables:**
```sql
-- Run SQL/03_DW_Dimension_Tables.sql
-- Run SQL/04_DW_Fact_Tables.sql
```

**Step 4 — Create Stored Procedures:**
```sql
-- Run SQL/05_Dimension_Stored_Procedures.sql
-- Run SQL/06_Fact_Stored_Procedures.sql
```

**Step 5 — Run SSIS Packages:**
- Open HealthETL.dtproj in Visual Studio 2022
- Run Master_ETL.dtsx to execute all 22 packages

**Step 6 — Open Power BI:**
- Open PowerBI/Healthcare_Analytics.pbix
- Update data source connection to your SQL Server
- Refresh data
